# Prefix Studio · TabPrefix 3.0.3

Откройте `/lptab webeditor [group]` или перейдите в Prefix Studio из `/lptab design [group]`. Для редактирования нужно `tabprefix.webeditor`; указанная группа требует `tabprefix.prefix.manage`. При установленном LuckPerms используются его действующие группы; без него сохранён самостоятельный режим групп.

## Композиция имени

1. Выберите «Префиксы» или «Суффиксы» в левом меню.
2. Нажмите основной элемент либо добавьте текст, PNG или GIF. Дополнительный элемент может совмещать текст и изображение.
3. Выберите текстовую или графическую рабочую область. Загрузите файл, обрежьте его, настройте размещение; текст поддерживает MiniMessage или legacy.
4. Переставьте дополнительные элементы стрелками, настройте интервал или временно выключите элемент. Основной элемент не удаляется; дополнительные удаляются отдельно.
5. Полный результат виден рядом с именем. Дождитесь «Сохранено · авто»; Ctrl/Cmd+S отправляет правку сразу. Коды в игре вводить не требуется.

С каждой стороны есть основной элемент и максимум 32 дополнительных. Для основного текстового суффикса можно выбрать свой текст, metadata LuckPerms либо «Нет». Изображение и дополнительные суффиксы независимы от источника основного текста. При наличии собственного текста основной источник становится Custom.

Вся цепочка сохраняется атомарно. Смена выбранного элемента не удаляет остальные; открытые редакторы автоматически подхватывают новую версию. Если другой администратор изменил то же поле, появится выбор своей или серверной версии. Изменение одной группы общего правила сохраняет префиксы/суффиксы остальных групп.

## Изображения

| Настройка | Поведение |
|---|---|
| Вписать / заполнить / растянуть | Сохраняют прежние contain / cover / stretch варианты |
| Исходные пропорции | Холст рассчитывается из пропорций источника с ограничением размера |
| Ширина и высота холста | 0 — автоматический размер; явно можно указать 1–256 пикселей |
| Девять якорей | Прижимают изображение к углу, краю или центру холста |
| X/Y-сдвиг | Перемещает изображение относительно выбранного якоря; наружная часть обрезается |
| Высота в игре / baseline | Задают экранный размер и вертикальное положение независимо от пикселей файла |
| Pixel / Smooth | Выбор интерполяции для пиксельной графики или плавных изображений |
| Пресеты | Значок, бейдж, лента и пропорции исходника |

Глиф ограничен 256 × 256 пикселями; вычисляемая ширина в игре — до 500 GUI px. GIF сохраняет задержки кадров и те же параметры размещения для каждого кадра. Разные элементы могут иметь разные размеры и метрики. Большие изображения и нестандартный baseline проверяйте с GUI Scale игроков.

## Адаптивный TAB

В Display Studio → TAB включите «Адаптивный макет» и настройте промежуток столбцов. Учитываются реально загруженные изображения, их размеры, baseline и максимальная ширина GIF-кадров. Пока пак не загружен, работает текстовый вариант.

Исходная сетка остаётся 4 × 20. По умолчанию компактный TAB отправляет только активные ячейки, подстраивает число колонок и уменьшает изображения пропорционально доступной строке. Полная сетка выбирается отдельно. В обычном TAB высотой и колонками управляет клиент; сервер передаёт составленное имя и его глифы.

Подложка ячейки имеет переключатель «Под ширину имени». Она расширяется шагами 16 GUI px до 400, начиная с заданной минимальной ширины. Более длинный текст сохраняется целиком и может выступать за максимально подготовленную подложку. Для строгой ширины выключите переключатель.

## Темы и анимации

Кнопка «Тема» доступна в обоих редакторах. Выберите Midnight, Paper, Aurora, Sunset, Ocean или Mono, либо измените палитру и скругления. Экспортируйте JSON, чтобы перенести тему в другой браузер; импорт принимает только параметры темы. Серверное оформление не меняется.

Переходы интерфейса можно выключить. Текстовые эффекты оформления настраиваются в инспекторе Display Studio: прокрутка, кадры, отскок, печатная машинка, блик, цветовая волна, пульсация и мигание. Личный переключатель анимации игрока продолжает останавливать текст и GIF.
