# TabPrefix 3.0.4

## Ячейка TAB

По умолчанию `artwork.boxes[].fit = ROW`. Фон растягивается на штатную строку: ширина имени + 13 GUI px под пинг и край, дополнительно 9 px при наличии головы. Имя передаёт только свою ширину; изображение возвращает курсор к исходной позиции. Оформление больше не раздувает нативную строку, которую само пытается закрыть. Для смешанных оформленных и обычных строк фиксируется общий advance. Для 1–4 колонок заранее строятся варианты с головами и без них.

Голова рисуется клиентом перед именем, поэтому в фоне оставлено прозрачное окно 8 × 8. Настоящий пинг клиент рисует поверх фона справа. Высота фона равна штатным 8 px, межстрочный интервал сохраняется. Во всю строку не применяется внешний отступ карточки. Для прежнего отдельного оформления выберите «Отдельная карточка» (`fit = CONTENT`); её отступ остаётся доступным.

`tabHeads = AUTO / ON / OFF` задаёт геометрию. Авто учитывает online-mode, настройку BungeeCord и доступную настройку Velocity в Paper. Прокси не всегда позволяет серверу достоверно определить шифрование клиентского соединения. Если режим отличается от фактического клиента, выберите «Есть головы» или «Нет голов» в «Интервалы и оформление». Эта настройка описывает клиентскую строку и не меняет наличие голов в самом Minecraft.

Предпросмотр показывает отдельные области головы, текста и пинга. Полная рамка окружает всю строку; внешнее поле скрыто в этом режиме. Сохраняются поддержка выбора исходной ячейки после перестроения, клавиатурная навигация, темы и импорт старых дизайнов.

## Чёткий скорборд

В прежнем bitmap-пути высота глифа включала пустое место до отрицательного Y. Ограничение атласа 256 × 256 заставляло уменьшать плотность верхних элементов. Простое добавление ещё одного большого PNG не устраняло причину.

`hudQuality = HD` использует локальные bitmap-глифы с плотностью 4 и коротким вертикальным полем для прозрачных меток. При уменьшении применяется фильтрация площади пикселя: тонкая рамка не выпадает из-за выборки ближайшего пикселя. Фильтр ограничен границами каждого глифа и не подмешивает соседние буквы атласа. Патч шейдера текста перемещает только распознанные глифы TabPrefix на нужный Y. Обычные шрифты и изображения без парной метки остаются на штатном пути. Фигуры и рамки продолжают заново рисоваться из векторов под размер. Переменная ширина букв сохраняется: атласы группируются по фактической ширине, а не превращают шрифт в моноширинный. Атласы кэшируются с ограниченным размером, служебные пиксели копируются без потери каналов.

Для графических подложек подавляется только их смещённая теневая копия. Цвета текста сохраняются. На клиентах с поддержкой `shadow_color` продолжает работать отключение тени через компонент. Служебные метки исключаются из фильтра и не видны в интерфейсе.

Патч включается для проверенных интерфейсов 1.21.2–1.21.5 (старые uniform-переменные), 1.21.6–1.21.8 (uniform-блоки), 1.21.9–1.21.11 (GLSL 330) и 26.1 (новая функция lightmap). Шаблоны сверены с файлами соответствующих выпусков Minecraft. На других версиях, включая 26.2/26.3, остаётся прежний bitmap-путь: интерфейс их шейдеров этим выпуском не предполагается совместимым.

Если другой ресурс-пак или мод заменяет `rendertype_text.vsh` или `rendertype_text.fsh`, выберите «Совместимость с шейдерами» (`hudQuality = COMPATIBLE`) и примите обновлённый пак. Этот режим не содержит shader override и сохраняет ограничения детализации при больших отрицательных смещениях. HD проверен отдельным OpenGL-рендерером; это не проверка установленного стороннего шейдера или Minecraft-клиента.

## Обновление

1. При остановленном сервере замените JAR и запустите сервер целиком.
2. Примите новый ресурс-пак. Renderer повышен до 6; при обычной автоматической пересборке старый пак обновляется сам. Если автоматика отключена, выполните `/lptab pack rebuild`.
3. Откройте новую сессию через `/lptab design` или `/lptab webeditor`. Старые тексты, картинки, группы и рисунки сохраняются.

Реальная детализация зависит от разрешения экрана и GUI scale. Низкое исходное разрешение загруженного фото/GIF не повышается как у векторных фигур. Нативный TAB также ограничивает ширину размером окна клиента; для очень крупного GUI уменьшите общую ширину TAB в редакторе. Скриншоты пользователя просмотрены; итоговая игровая отрисовка в этой среде не проверялась. Подробности автоматических проверок — в [VALIDATION.md](VALIDATION.md).
