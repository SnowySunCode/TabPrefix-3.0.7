# HD: версии и поверхности

## Матрица

| Minecraft | Режим | Что улучшено |
|---|---|---|
| 1.12–1.12.2 | HD Unicode-текстуры | PNG/GIF на страницах 1024 × 1024; прежние метрики, коды и размер в интерфейсе |
| 1.13–1.16.5 | Bitmap | Максимальная доступная плотность; сохранение отрицательных краёв и нижних выносов букв |
| 1.17–1.18 | HD, интерфейс 117 | Старые матрицы и сферическая fog distance |
| 1.18.1 | HD, интерфейс 1181 | Цилиндрический fog и IViewRotMat |
| 1.18.2–1.20.4 | HD, интерфейс 1182 | FogShape с прежними матрицами |
| 1.20.5–1.21.1 | HD, интерфейс 1205 | Обновлённая fog distance, прежние пути imports |

HD-текст использует плотность 4, исходное покрытие и поле расстояний для сглаживания при увеличении. Настоящее жирное начертание выбирается отдельными кодами без повторного сдвинутого прохода; обычный и жирный текст имеют собственные метрики. В bitmap-режиме 1.13+ жирное начертание также подготовлено отдельно, но фильтрация остаётся нативной.

Фигуры скорборда и TAB, подложки шапки/футера используют плотность 8; если суммарные исходные кадры превысили бы 24 миллиона пикселей, весь векторный макет использует плотность 4. Это ограничение рабочих кадров, а не гарантия общего потребления памяти. Текст, экранные изображения и значки компактного TAB сохраняют плотность 4. Скругления панелей и прямоугольников рассчитываются по площади круговой границы; заливка и рамка имеют одно покрытие и одну прозрачность. Фрагменты имеют поля с реальными соседними пикселями, а каждый центр выходного пикселя принадлежит одному фрагменту. Кадры GIF остаются отдельными, ширина компактного значка стабильна. Сам компактный значок занимает один глиф, чтобы сокращение строки и веб-предпросмотр не разделяли его на части. Стандартные шрифты, исходные фото-глифы Prefix Studio и немаркированные текстуры сохраняют нативный путь и своё исходное разрешение. Плагин не повышает детализацию низкого исходника.

Пак генерируется под версию сервера. Смешанные версии клиентов через ViaVersion этим изменением не решаются. Неизвестные будущие интерфейсы не включаются автоматически.

## Почему не одинаковый HD на 1.12–1.16

Core shader override доступен начиная с 1.17. В более старых клиентах нельзя тем же ресурс-паком выполнить произвольный сдвиг вершины и фильтрацию площади глифа. Для больших отрицательных Y в bitmap-пути приходится сохранять пустое вертикальное поле, а глиф ограничен размером клиентского атласа. Четырёхкратное разрешение старой Unicode-страницы улучшает фото, но не добавляет произвольное позиционирование. Для одинакового современного HUD на этих клиентах потребуется отдельное клиентское расширение; оно в JAR серверного плагина не входит.

## Настройка

В редакторе выберите «Качество графики HUD → Высокое качество». Для ресурс-пака или мода, который сам меняет шейдер текста, используйте «Совместимость с шейдерами». Это убирает все shader overrides и сохраняет bitmap-ограничения. Версия 1.12 использует HD Unicode-страницы без core shader override.

Перезапустите сервер после обновления JAR и примите новый ресурс-пак. Renderer 9 обновляет старый HUD при автоматической пересборке. Если она отключена, выполните `/lptab pack rebuild`. Коды глифов, UUID assets, настройки групп, рисунки и база данных не меняются.

## Источники интерфейсов

Нативные шаблоны `resources/shaders/hd/<interface>/text.vsh` и `text.fsh` сверены с shader assets Minecraft Java Edition. История оригинальных ресурсов: [misode/mcmeta](https://github.com/misode/mcmeta). Использованы refs `1.17-assets`, `1.18.1-assets`, `1.18.2-assets`, `1.20.5-assets`, `1.21.2-assets`, `1.21.6-assets`, `1.21.9-assets`, `26.1-assets`, `26.2-assets`, `26.3-assets`, пути `assets/minecraft/shaders/core/rendertype_text.*` до 26.1 и `core/text.*` с 26.2. Includes соответствующих выпусков сохранены в `tests/shader-reference.json` для offline GPU QA.

Основные изменения ограничены распознаванием подписанных углов глифа, его Y, подавлением тени графики и выборкой собственной ячейки. Нативные формулы fog, lightmap, grayscale, see-through, GUI и OIT сохранены в шаблонах. Полный игровой запуск и сторонние моды отдельно не проверялись.
