# TabPrefix 3.0.3

## Рамки и линии

Подложки строятся из векторов в четырёхкратном исходном разрешении. Большая панель разделяется на небольшие bitmap-глифы и собирается с точными смещениями. Уменьшение целой панели до одного маленького PNG больше не определяет качество её краёв. Одинаковые части с одинаковым вертикальным положением используют один глиф и одну текстуру, включая скопированные стили. Каждая часть помещается в клиентский атлас 256 × 256; плотность выбирается с учётом высоты и вертикального смещения. При очень высоком отрицательном смещении (выше −248 GUI px) или исчерпании приватных кодов остаётся прежний допустимый вариант.

Варианты ширины и компактной высоты TAB заново рисуются из векторов. Толщина обводки задаётся в GUI-пикселях и не растягивается вместе с готовой картинкой. При изменении ширины сохраняются круглые окончания линий, радиус и ровная рамка. Градиент следует за геометрией. Обводка подложки строится внутри её границ; слишком толстая рамка ограничивается доступной площадью и не обрезается по краю.

В редакторе толщину можно менять с шагом 0,25 (0–16 GUI px; у пера минимум 0,25). Дробные значения сохраняются через API и SQLite. Экспорт PNG из редактора использует плотность 4; старый API без поля `density` сохраняет прежние размеры, допустимы значения 1–4.

## Карточка TAB

У ячейки появился параметр `artwork.boxes[].inset`, по умолчанию 0,5 GUI px для `CELL` и 0 для других областей. Настройка «Отступ карточки» имеет слайдер. Компактная карточка занимает штатную строку высотой 9 px с внутренним отступом; текст остаётся в прежней строке. Новые пресеты ячейки используют более тонкую рамку и не добавляют толстую акцентную полосу. Предпросмотр показывает отдельную карточку на штатной подложке.

Штатный фон TAB рисует клиент, и серверный плагин не выключает его настройкой текстуры. Здесь он сохраняется как внешний фон строки: авторская рамка отделена от него отступом. Голова и значок настоящего пинга остаются штатными. Это не модификация шейдеров клиента.

Для графических компонентов TAB передаётся `shadow_color: 0`. На клиентах с поддержкой этого поля (1.21.4+) рамка и текст не получают смещённую копию тени. Для шапки и футера на соответствующем сервере используется нативный компонент с сохранением пары; при недоступности адаптера остаётся Bukkit. HUD также отключает тень через необязательный метод современного Bungee Chat API; старые API продолжают обычную отправку.

## Обновление

1. Замените JAR при остановленном сервере и запустите сервер целиком.
2. Примите обновлённый ресурс-пак: renderer повышен до 5, старый пак пересобирается. Если автоматическая пересборка отключена, выполните `/lptab pack rebuild`.
3. Получите новую ссылку редактора командой `/lptab design` или `/lptab webeditor`.

Качество проверяется по PNG из собранного пака, их метрикам и восстановлению составных кадров. Minecraft-клиент и Chromium в среде выпуска не запущены. Реальная детализация зависит от масштаба GUI и доступного разрешения глифов; PNG/GIF низкого исходного разрешения не превращаются в векторную графику.
