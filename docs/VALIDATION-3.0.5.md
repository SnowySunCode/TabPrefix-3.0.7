# Проверки TabPrefix 3.0.5

## Выполненная проверка изменений

Проверяется собранный `dist/TabPrefix.jar`, включая реальные PNG и JSON в генерируемых ресурс-паках. Конфигурация графических тестов задаётся отдельной неизменяемой fixture с настоящим `FeatureSettings`; Bukkit/YAML-конструктор настроек в этой группе не проверяется.

- `bash test-hd.sh --skip-build`: ArtworkIntegrationTest, ArtworkQualityIntegrationTest, HudFinishIntegrationTest, HdVersionsIntegrationTest. Проверяются точное восстановление векторных подложек, швы и дробная толщина, границы текстур, полная строка TAB с головами/пингом, неизменная плотность при отрицательном Y, целые края букв, повторная загрузка паков и переключение качества.
- HdVersionsIntegrationTest создаёт реальные паки для 1.17, 1.18.1, 1.18.2, 1.20.5, 1.21.2, 1.21.6, 1.21.11, 26.1, 26.2 и 26.3. Метрики сравниваются с PNG независимо; дополнительно проверены bitmap-паки 1.13.2/1.16.5 и совместимый режим 1.17/26.2/26.3. Кадры GIF с разной шириной рисунка сохраняют общий холст. Компактные HD-значки атомарны, их коды понятны существующему предпросмотру.
- Legacy 1.12: физическая страница 1024 × 1024, прежние UV/метрики, сохранение чужого символа на той же странице и перезагрузка. Это проверка текстур, а не современного HUD на старом клиенте.
- `python3 tests/hud-gpu.py .`: 788 проверок: реальная компиляция GLSL и рендеринг через surfaceless EGL, Mesa llvmpipe/OpenGL 4.5. Includes выпусков Minecraft сохранены в `tests/shader-reference.json`. Проверены десять интерфейсов, четыре варианта GUI/grayscale/see-through для 26.2/26.3, перемещение четырёх вершин, изоляция соседних глифов, сохранение обычных текстур и текста, подавление только тени графики и толщина 0.25–2 GUI px при GUI scale 1/2/3/4. Экранные и компактные TAB PNG/GIF проверяются по framebuffer; GUI-пайплайн 26.2/26.3 также действительно рисует изображение. Нативные OIT-ветви сохранены в исходных шаблонах; запуск всех OIT-проходов не заявляется.
- `node tests/live-save.mjs` — 28 проверок очереди сохранения; `node tests/state-sync.mjs` — 14 проверок синхронизации. Проверены синтаксис evolution.js и shell-скриптов.
- Просмотрены изображения фактического OpenGL-вывода скорборда, рамки TAB, латинского/кириллического текста и графического кадра.

## Сборка и границы

Изменённые production-классы скомпилированы с `--release 8` против проверенной поставки 3.0.4; неизменённые классы и runtime-библиотеки перенесены без перекомпиляции. Финальный JAR содержит 169 собственных классов с Java 8 bytecode. Проверяются CRC, отсутствие дублирующихся записей, сохранность лицензий, TTF и соответствие упакованных ресурсов исходникам.

Чистая полная пересборка и весь Bukkit/HTTP/DOM-набор 3.0.4 в этом выпуске заново не запускались: зависимости Maven в текущей среде недоступны. Полный стандартный путь сборки `build.sh` сохранён, зависимости закреплены прежними SHA-256. После подготовки зависимостей полный набор запускается через `bash test.sh --offline` и `bash test-compatibility.sh`. Предыдущий отчёт — [VALIDATION-3.0.4.md](VALIDATION-3.0.4.md).

Minecraft-клиент и серверы с реальными игроками не запускались. Не проверялись сторонние шейдерные паки, все модели GPU и смешанные версии через ViaVersion. HD для произвольного HUD на 1.12–1.16 этим JAR не добавляется; матрица режимов — [HD-COMPATIBILITY.md](HD-COMPATIBILITY.md).
