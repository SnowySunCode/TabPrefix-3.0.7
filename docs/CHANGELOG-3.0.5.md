# TabPrefix 3.0.5

- HD расширен с 1.21.2–1.21.11 / 26.1 на известные выпуски 1.17–1.21.11 и 26.1–26.3. Вместо предположения об одном интерфейсе используются десять версионных шаблонов.
- Для 26.2 устанавливается `core/text`; для 26.3 сохранены нативные `#include`, явные locations и OIT-функции. Другие Minecraft-текстуры продолжают нативный путь.
- Экранные PNG/GIF и изображения компактного TAB используют HD-глифы с плотностью 4. Значок TAB остаётся цельным для сокращения строки и предпросмотра; ширина GIF не скачет при изменении рисунка кадра. Настройки размещения и постоянные коды исходных глифов не меняются.
- В 1.12 страницы Unicode увеличены с 256 до 1024 px. Сетка UV, метрики и неиспользуемые символы сохраняются; старый пак автоматически обновляется по метке плотности.
- В bitmap-пути исправлено обрезание отрицательного левого края и верхних сглаженных пикселей букв.
- Идентичные фрагменты сравниваются до PNG-кодирования: повторная компрессия одинаковых текстур больше не выполняется.
- API сессии сообщает доступность shader HD и legacy HD-текстур. В редакторе указана действующая область поддержки.
- Renderer 7 требует новый HUD-пак; полная посадка строк TAB, режим совместимости и прежние документы сохранены.

Полный shader HD произвольного HUD на 1.12–1.16 этим серверным JAR не реализуется: нужен клиентский рендерер. Обычные исходные фото-глифы Prefix Studio сохраняют своё разрешение; HD-фильтр распространяется на их компактные TAB-варианты и экранные варианты. Подробности: [HD-COMPATIBILITY.md](HD-COMPATIBILITY.md).
