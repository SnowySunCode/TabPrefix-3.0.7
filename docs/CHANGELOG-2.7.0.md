# TabPrefix 2.7.0

## Исправления отображения

- Header, footer, sidebar и текст в ячейках TAB обновляют анимацию независимо от `refreshTicks`. Короткий текст тоже двигается, если выбрана «Бегущая строка». Цвета и Unicode-символы сохраняются.
- Текст футера редактируется прямо в списке строк. В «Табе мечты» существующая строка footer/header открывает инспектор по нажатию. Добавление элемента сразу открывает его текст. Исправлено касание ячейки на телефоне: оно выбирает ячейку для редактирования.
- Панель без цифр использует увеличенную растеризацию и встроенный пропорциональный шрифт DejaVu Sans. Добавлены размер текста, высота строки, ширина и отключаемая тёмная подложка. Частные глифы не заменяют цифры обычного шрифта.
- «Чёткий макет без цифр» выбирает настоящий sidebar с blank number format на 1.20.3+, либо шрифтовую панель для старых серверов. Нативный sidebar сохраняет objective и строки между обновлениями.
- Первые кадры пользовательских префиксов сохраняются для игроков, отключивших анимации, включая чат.
- Для сложного оформления лимит JSON design/preview/import поднят до 1 MiB в пределах серверного request limit.

## Группы

Редактор автоматически получает все загруженные группы LuckPerms с весом, отображаемым именем, префиксом и суффиксом. Есть поиск, обновление и выбор нескольких групп для общего префикса. Отдельное правило может иметь текст, картинку из каталога, цвет имени и суффикс. Изменения записываются в общий документ оформления и применяются к TAB, name tags и чату через существующий контроллер префиксов. Узлы LuckPerms не изменяются.

Создание, загрузка и удаление группы инициируют обновление серверного кэша. Открытый редактор обновляет каталог каждые 12 секунд и при возвращении на вкладку. Ручное обновление также доступно. Основная/весовая группа игрока определяется настройкой `use-primary-group`, как раньше. Без LuckPerms остаются локальные группы и `tabprefix.group.<group>`.

## Боссбары

- Привязка к существующему мобу по UUID, типу, имени, scoreboard-тегу или ближайшему живому мобу.
- Только загруженные сущности в мире зрителя и в заданном радиусе. Чанки не загружаются; мобы не создаются.
- Заполнение следует за реальным здоровьем. При смерти, выгрузке или выходе из радиуса полоса скрывается. Поиск в каждом мире выполняется один раз за тик отображения.
- Переменные `{boss_name}`, `{boss_health}`, `{boss_max_health}`, `{boss_type}`, `{boss_uuid}`.
- Календарь с часовым поясом, днями недели, числами месяца, месяцами, часами, минутами и временным окном. Ночные окна относятся к дню начала, включая часть после полуночи.
- Случайный показ с интервалом попыток, вероятностью и длительностью. Одна попытка на событие общая для всех игроков: число игроков и частота тиков не увеличивают шанс. Попытки выровнены по интервалам реального времени.
- До 16 правил вероятности по дням и часам. Первое совпадение определяет шанс; иначе действует общая вероятность. Полоса всё равно соблюдает календарь, мир, права и личный переключатель игрока.

## Интерфейс

Общая новая тема во всех редакторах; светлый и тёмный варианты, SVG-значки, доступный контраст, компактные поля и раскрываемые настройки. Header и footer находятся рядом. Текст строк вводится на месте; инспектор используется для форматирования и анимаций. Сохранение остаётся явным — «Применить к серверу». Есть undo/redo и экспорт документа.

## Проверки и границы

См. `VALIDATION.md`. Minecraft-клиенты и настоящий сервер не запускались. На 1.12 панель без цифр остаётся в открытом TAB; свободный XY и выборочное удаление чисел стандартного старого sidebar не добавлены. Для bitmap HUD нужен принятый vanilla resource pack. Разрешение и GUI Scale игрока не передаются серверу, поэтому координаты требуют проверки в игре.
