# Изменения

## 3.0.7

Аналитические скругления, единое покрытие заливки/рамки, плотность фигур 8 с ограничением рабочих кадров, реальные соседние пиксели и единственное владение центром пикселя на стыках, Renderer 9. [Подробности](CHANGELOG-3.0.7.md).

## 3.0.6

Настоящее жирное начертание, отдельные метрики и поле расстояний HD-текста; сохранность выносных элементов и RGBA-покрытия в grayscale-ветке. [Подробности](CHANGELOG-3.0.6.md).

## 3.0.5

HD для известных интерфейсов Minecraft 1.17–1.21.11 и 26.1–26.3; экранные и компактные TAB PNG/GIF в HD, Unicode-текстуры 4× на 1.12, защита краёв букв и меньше повторного PNG-кодирования. [Release notes](CHANGELOG-3.0.5.md).

## 3.0.4

Полная ширина штатной строки TAB, область пинга внутри рамки, отдельная геометрия для клиентов с головами и без них. HD-путь сохраняет разрешение скорборда при отрицательном Y; добавлены режим совместимости с шейдерами, точные метки глифов и кэш атласов. Предпросмотр и настройки размещения согласованы с новой геометрией. [Release notes](CHANGELOG-3.0.4.md).

## 3.0.3

Дробная толщина, составные подложки, внутренние рамки и отступ карточки. [Release notes](CHANGELOG-3.0.3.md).

## 3.0.2

Компактный TAB, ограничения баннеров, работа с содержимым в главном предпросмотре. [Release notes](CHANGELOG-3.0.2.md).

## 3.0.1

Единый серверный снимок для редакторов, восстановление черновиков в новой вкладке/сессии, проверка версий личных настроек и защита от поздних ответов. Быстрая готовность без загрузки всего GIF, сохранность выбранной картинки при вводе, живые каталоги и черновик глифа. Целые буквы в очень узкой строке, запасные HUD-строки, сохранение экранного текста при пересборке и обновление старого renderer пака. [Release notes](CHANGELOG-3.0.1.md).

## 3.0.0

Составные префиксы и суффиксы, отдельные PNG/GIF с разными размерами, адаптивный TAB и расширяемые подложки ячеек. Исправлена потеря букв при изменении размера HUD-скорборда и обновлении ресурс-пака. Шесть тем, собственная палитра, новые текстовые эффекты, якоря и размещение изображений; `/lptab design [group]` использует общий механизм открытия редактора. [Release notes](CHANGELOG-3.0.0.md).

## 2.0.2

- Адреса активных интерфейсов сервера, автоматический выбор подсети игрока и `/lptab linkwifi` с интерактивными строками.

- EN/RU, справка, completion и инструкция по обновлению без удаления данных.
- Пройдены 252 автоматические проверки, включая 52 новые сетевые и 19 браузерных.

Полные release notes: [CHANGELOG-2.0.2.md](CHANGELOG-2.0.2.md). Настройка LAN и пределы доступа без проброса: [NETWORKING.md](NETWORKING.md).

## 2.0.1

- Убран audience provider из канала ответов команд; native Bukkit отправляет обычный текст всем CommandSender.
- Для interactive сообщений используется Spigot SYSTEM и JSON bridge, сохраняющий click/hover/RGB.
- Ошибка rich API даёт читаемый text/URL fallback и одно предупреждение без session tokens.
- Добавлен `/lptab doctor` с `tabprefix.status`, прямым ответом, readiness/version и отчётом в лог для игрока; доступен также `/tabprefix:lptab doctor`.
- Добавлены 39 проверок production MessageService и native API calls. Пройдено 200 проверок всего.
- Storage schema, formats, defaults и workflow сохранены; обновление заменяет JAR при остановленном сервере.

Лог пользователя подтверждает отсутствие ответа, но не содержит startup/packet diagnostics. Сборка устраняет зависимость ответов от audience registry; конкретный сервер проверяется doctor после установки.
