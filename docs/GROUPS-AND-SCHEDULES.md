# Группы и расписания — быстрый старт

Откройте `/lptab design`, оставаясь на сервере. Изменения сохраняются и применяются автоматически; дождитесь статуса «Сохранено · авто».

## Префикс для нескольких групп

1. В разделе TAB найдите «Группы LuckPerms».
2. Отметьте группы, введите префикс и нажмите «Назначить выбранным».
3. В списке правил групп выберите созданное правило. Можно добавить картинку из каталога, цвет имени или суффикс. Дополнительные группы перечисляются через запятую.
4. Примените оформление. Любая группа может входить только в одно правило. Общий префикс переопределяет прежний префикс TabPrefix/LuckPerms для этих групп; режим «Из LuckPerms или прежних настроек» возвращает прежний источник. «Без префикса» скрывает его.

Картинка показывается после успешной загрузки ресурс-пака игроком. Правила не выдают разрешений и не меняют настройки самого LuckPerms. Показ группы игрока следует существующей настройке выбора основной/весовой группы.

## Полоса здоровья настоящего моба

1. Создайте боссбар и откройте «Привязать к настоящему боссу».
2. Для ближайшего Wither выберите поиск по типу и введите `WITHER`; для именованного моба — поиск по имени; для конкретной сущности — полный UUID.
3. Задайте радиус, например 64 блока. Для нескольких мобов с одинаковым типом/именем/тегом выбирается ближайший.
4. Текст: `<red>{boss_name}</red> <white>{boss_health}/{boss_max_health}</white>`.

Привязка заменяет выбранный способ заполнения реальным здоровьем. Плагин создаёт собственную полосу и не изменяет здоровье моба или полосы других плагинов. Привязка скрывается при отсутствии подходящего моба.

## По расписанию

«Когда показывать» → «По расписанию», часовой пояс `Europe/Moscow`. Отметьте пн–пт и задайте 18:00–22:00. Пустые месяцы/даты/часы/минуты означают любые. Допустимы диапазоны `1,3-5`. Все непустые ограничения должны совпасть одновременно. Начало включено, конец исключён. При 22:00–02:00 часть после полуночи относится к предыдущему дню недели и дате.

## Случайный показ

Режим «Случайные появления»: 25%, каждые 30 минут, длительность 60 секунд. Это в среднем одно появление за 2 часа, а не гарантированный показ каждые 2 часа. Попытка общая для сервера; игрок, вошедший во время успешного события, увидит оставшуюся его часть. События выровнены по интервалам Unix-времени, независимо от времени входа игрока.

Правило: дни `6,7`, часы `18-22`, вероятность 70%. По выходным в эти часы используется 70%; иначе — общие 25%. При нескольких совпадениях применяется самое верхнее правило. Длительность показа не может превышать интервал между попытками. За пределами календаря полоса скрыта. После перезапуска случайная последовательность меняется.
