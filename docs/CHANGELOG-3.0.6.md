# TabPrefix 3.0.6

Исправление отрисовки текста TAB, скорборда и свободного HUD.

- Жирное начертание растеризуется шрифтом, выбирается отдельным кодом и не включает нативный второй проход `§l`. Метрики, смена цвета, сокращение строки и общие профили согласованы с реальным начертанием.
- Второй приватный Unicode-план используется только для жирных глифов. Бюджет обычных кодов макета не сокращается. UUID изображений и прежние назначения глифов не меняются.
- HD-текст объединяет исходное покрытие с полем расстояний: усреднение при уменьшении и восстановление сглаженного контура при увеличении. Соседние ячейки атласа не участвуют в выборке. Добавлен свободный край для полного контура буквы.
- Расчёт поля расстояний выполняется один раз для шрифта/размера/начертания и переиспользуется строками с разными координатами.
- Обе приватные плоскости распознаются существующими адаптерами отключения тени. Тёмный цвет букв сохраняется.
- Приватные RGBA-глифы обходят преобразование `.rrrr` в grayscale-ветке шейдеров 26.2/26.3; нативная обработка обычных ресурсов сохранена.
- Renderer 8 инициирует обновление паков. Старая доставленная ревизия продолжает использовать старые метрики до принятия нового пака.

## Обновление

Остановите сервер, замените JAR и запустите сервер. При включённых `resource-pack.auto-build` и `resource-pack.auto-send` пак пересоберётся и отправится автоматически. Примите новый пак. При отключённой автоматике используйте `/lptab pack rebuild`.

Всё остаётся в одном серверном плагине с генерируемым ресурс-паком. Матрица версий не расширяется: HD-шейдеры поддерживаются с 1.17; на 1.13–1.16.5 остаётся bitmap-путь, на 1.12 — прежний Unicode-путь. Режим совместимости не включает поле расстояний. Minecraft-клиент и реальные серверы при разработке этого выпуска не запускались; подробности — в [VALIDATION.md](VALIDATION.md).
